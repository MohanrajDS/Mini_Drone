# 🛩️ Micro Drone Flight Controller 

A compact, custom-designed flight controller PCB for micro drones, integrating the MCU, motor drivers, and IMU on a single board of approximately **20 mm x 20 mm**.

This project focuses on achieving high integration, low weight, and minimal footprint suitable for coreless/mini brushless motor-based micro aerial vehicles.

---

## 📌 Project Overview

This board is a complete flight control solution for a micro drone, designed to:

- Control multiple motors directly using onboard motor drivers  
- Read motion data from an IMU sensor  
- Run custom firmware for stabilization and control  
- Fit within extremely small drone frames (~2×2 cm)

The design targets DIY micro drones and research/learning in embedded systems, control, and PCB miniaturization.

---

## 🔧 Key Features

- ✅ Ultra-compact PCB (~20 mm × 20 mm)
- ✅ Integrated microcontroller
- ✅ Onboard motor driver stages
- ✅ IMU for attitude sensing
- ✅ Battery power input
- ✅ Designed for lightweight micro drones
- ✅ Fully custom PCB (schematic + layout)
